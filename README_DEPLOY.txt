Mess Quest clean static deploy

This folder contains the playable Mess Quest app from the uploaded ZIP, cleaned for GitHub Pages/static hosting.

Included:
- index.html
- built Vite JS/CSS bundle
- required game backgrounds
- required generated PNG assets

Excluded deliberately:
- node_modules
- work folder
- __MACOSX
- .DS_Store
- reference sheet / verification assets
- bulky unused development output

Deploy:
Upload the contents of this folder to the MessQuest branch root, or use it as the GitHub Pages static site folder.
